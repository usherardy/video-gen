# Assets captured from promptitin.com

Captured with `curl` and Playwright (headless Chromium). Everything is used as-is: real pixels are cropped and animated, never redrawn.

| File | What it is |
|---|---|
| `logo.png`, `logo-white.png` | Real logo mark, 471x474 |
| `generatePrompt.png` | Real Generate screen (1920x1080), from the site's feature section |
| `PromptEnhancer.png` | Real Optimize screen: 40% score meter, Enhanced Prompt panel |
| `PromptLibrary.png` | Real Optimize UI on a blue backdrop; the site uses it for "Prompt Library" |
| `hero-bg-opt.jpg` | Real hero backdrop |
| `shot-hero.png` | Live homepage hero, launch-offer modal removed for the capture |
| `shot-full.png`, `shot-section1-3.png` | Full page and feature-section captures |
| `fonts/Geist.woff2`, `fonts/GeistMono.woff2` | Site fonts (latin subset), from the site's own CSS |
| `*.css`, `home.html` | Source used to read colors and fonts |

Brand: accent `#7c3aed`, ink `#111827`, background `#fafafa`. Headline serif is Georgia italic on the site; the video uses Gelasio (metric-compatible).

Not captured: `/prompts` and `/prompt-builder` render "Something went wrong" in headless Chromium, so no live app states are used.

Copy used (from the site): "Turn vague prompts into ones that actually work", "Rough idea -> structured prompt", "Paste pre-made prompt. Get polished.", "Save once. Reuse anywhere.", "1,000 credits / month" (Starter plan), "180+ people using it", "5.0 Chrome Web Store".
